# HR月报模板 v2（本地候选）

2026年10月19日确认三套全量接入：管理纪要（兼容ID `forest`）、数据简报（`minimal`）、团队月刊（`warm`）。沿用现有接口、角色和章节选项，不改变统计口径。生产运行仅需现有Python、openpyxl和Pillow，无须Office、Node或Codex。

每套PPTX包含17种命名版式，`*-layouts.json`记录版式与页号映射。`hr_monthly_layouts.py`按形状名称填充，而非按文字形状索引猜测。包含概览、分类图、4/5/7列表格、组均分图、趋势、单/双/四照片、说明、结束、月刊积分、统计趋势合页、签卡人条形图和优秀员工名单。原生图表每页独立绑定工作簿。表格数据18pt，按列宽和换行高度分页，极长字段续行，不截断姓名或漏行。

三套封面分别使用独立生成的虚构场景，明确标识“视觉示意图，非真实活动照片”。封面示意图不作为业务活动材料。活动页只使用本次上传照片，无照片则隐藏，不自动用生成图补充活动。

照片保持比例完整适配、不裁切，清除元数据，按单图/双图/四图显示尺寸缩放。透明或较适合无损的内容保留PNG，普通照片优先JPEG；相同编码素材只入包一次。未使用版式、示例工作簿及备注不进入最终报告。

修改模板时必须保留命名区域、图表/表格原生类型和JSON版式映射。使用专项测试和模拟报告检查填入数据后的实际文件，不只检查空模板。模板包内的占位文字不能原样用于正式报告。历史v1如下，仅供追溯。

## 历史v1

已由用户确认的森林都市（forest）、简约汇报（minimal）、温暖团队（warm）三套16:9原生PPTX。素材来自本任务原创Image Gen生成，仅作背景装饰，不冒充员工或真实活动。保留微软雅黑、原有标题与表格图表样式。

模板包含明确示例数据，不能原样当正式报告下载。生产导出由`app/hr_monthly_pptx.py`回填并删除未使用示例页、备注、工作簿，使用同一份`app/hr_monthly_report.py`数据。顺序为封面1、概览2、减分3/4、加分5/6、发放7、认可8/9、小组10、优秀11、PR12/13/14、说明15、照片16/17/18、生日19、结束20。

替换模板时须同步核验文字形状索引、表格列数/容量、原生图表与内嵌工作簿路径、照片背景框，运行专项测试与导出渲染。当前无需新增Python依赖或额外表。
