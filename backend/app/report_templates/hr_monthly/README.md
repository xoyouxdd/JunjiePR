# 生产HR月报模板 v1

已由用户确认的森林都市（forest）、简约汇报（minimal）、温暖团队（warm）三套16:9原生PPTX。素材来自本任务原创Image Gen生成，仅作背景装饰，不冒充员工或真实活动。保留微软雅黑、原有标题与表格图表样式。

模板包含明确示例数据，不能原样当正式报告下载。生产导出由`app/hr_monthly_pptx.py`回填并删除未使用示例页、备注、工作簿，使用同一份`app/hr_monthly_report.py`数据。顺序为封面1、概览2、减分3/4、加分5/6、发放7、认可8/9、小组10、优秀11、PR12/13/14、说明15、照片16/17/18、生日19、结束20。

替换模板时须同步核验文字形状索引、表格列数/容量、原生图表与内嵌工作簿路径、照片背景框，运行专项测试与导出渲染。当前无需新增Python依赖或额外表。
