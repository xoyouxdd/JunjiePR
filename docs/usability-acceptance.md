# 日常操作保护与任务验收

本轮内容并入本地候选版本 `2026.10.16.4`。提交、打包或上线状态须以实际验收记录为准。

## 已实现行为

- 登记、公告等 `.form-stack` 表单发生输入后，切换导航、登记模式、公告工作区或退出前复用现有确认弹窗；取消后保留当前内容。刷新/关闭由浏览器提供原生离开提醒，移动系统强制结束进程不能保证触发。正文与文件不新增浏览器持久存储。
- 提交成功清除相应编辑标记；校验失败或连接中断保留当前填写。现有幂等登记在结果不确定后保留原键，须先查记录再决定重试。普通提交显示进行中，等待15秒提示仍在确认；写入不因切页自动取消、不自动重发。
- 初始化网络/服务器故障原页提供重新连接；仅401按原流程跳登录。普通页面加载失败可重新加载；GET等待30秒后给出超时提示，切页仍取消旧读取。
- 补材料待办直达全部圈协作范围，未选择协作范围时默认本人圈。材料队列按50项翻页，可筛选待补或生成失败，接口提供总量，单页最多200项。
- 主管待跟进明细只含分配给本人事项；GSM/TA GSM明细限现有管理范围在职人员，均包含历史未结。负责人可进入原登记页面，带出员工/日期/事项提示；查阅下属事项不获得代处理权限。
- 月结的四类阻塞事项可查看员工、日期、事项、负责人，按页读取。与检查清单共用查询条件，沿用月结查询权限、原月份和圈范围，不展示材料正文、下载地址，不赋予HR审核权限。

## 本地自动验收

独立测试数据目录，模块分别运行；浏览器使用真实前端和合成API，不连接生产。

- `test_usability_workflows.py`：207项材料翻页不遗漏、失败筛选、本人/跨圈范围、历史跟进、GSM计数与详情一致、HR只读范围与越权拒绝。
- `test_month_close.py`：原月结门禁、补结和重开，以及签卡阻塞明细定位。
- `frontend_modules.cjs`：手机离开取消/确认、断网后保留内容和原幂等键、启动重试、提交状态、待跟进/月结明细分页、材料待办范围和翻页、响应式布局与原流程回归。
- `frontend_api_errors.cjs`、`view_lifecycle.cjs`：读取超时、切页取消、写入不自动取消、无法确认写入结果提示、旧请求不覆盖新页面。

命令见[本地运行和测试](getting-started.md)。测试结果与证据写入 `output/usability-implementation-20261016/ACCEPTANCE.md`，该输出不代表上线。

## 真人手机验收表

先在隔离测试环境使用测试账号和材料。请各选一位实际员工、主管和HR完成以下任务，记录设备/浏览器、耗时、误触、返工、求助次数与结果；不要让测试写入正式记录。

| 使用者 | 任务 | 通过标准 |
|---|---|---|
| 员工 | 填登记后切页并取消，再完成图片登记；查看结果 | 取消保留内容；结果明确且只有一份记录 |
| 员工 | 提交时模拟断网，恢复后先核对记录 | 不误认为已失败、不盲目重复登记 |
| 主管 | 点补材料待办、翻页、筛选失败、完成测试补充 | 数量对应范围，能找到旧项，完成后待办更新 |
| 主管/GSM | 查历史未结跟进与负责人 | 主管可进原登记；GSM查下属不获得代处理权 |
| HR | 选历史月份和本圈，查月结阻塞明细 | 能找到具体事项和负责人；没有额外审核按钮 |
| 三类人员 | 刷新/关闭未提交页面、断网打开再重试 | 浏览器支持时提示离开；网络故障原页可恢复 |

自动化手机尺寸检查不能代替真机、真实操作者和真实网络验收。当前没有用户访谈、真人签字或真实容量压测结论。
