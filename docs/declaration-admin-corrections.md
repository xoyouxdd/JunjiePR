# 声明统计：处分类型更正及作废/还原（仅本地）

桌面明细、手机卡片增加处分类型下拉框（安全、礼仪、考勤等）和逐条作废/还原按钮。沿用现有处分等级功能，不新增导航入口。

新增接口按现有SYSTEM_ADMIN权限鉴权，适用于ADMIN、HR01等最高管理员账号。景点圈HR、HR_ADMIN、经理、主管、员工不能调用类型更正或还原接口。其他页面的原登记人作废权限继续保留。

类型更正允许独立记录的active、pending_material、material_failed、void状态，不改变业务状态、事件日期、材料、内容或登记人。按事件日期的目标类别规则核算分值，保留原记录等级分值快照；无快照采用原等级标准，固定扣分类别使用目标类别分值。生效记录检查同类处分升级约束。

作废退出计分，还原恢复voided_from_status。待补材料、材料失败仍保持原状态；恢复原生效记录要求原材料仍有效，并检查重复处分。缺少可核实原状态的旧作废记录不能直接还原。升级关联（含仅有工单外键关联）、已月结、材料处理中记录继续保护。

每次操作填写原因并记录审计，事务内保存，审计失败回滚。SQLite写锁保护状态读取及写入。类型修改核对原类型、等级、状态；还原核对作废时间、类型、等级。旧表单和重复提交不能重放。查询、导出使用更正分类，写入后使计分缓存失效。

等级更正为生效记录时，同样使用既有同类处分升级校验；不允许通过降级更正绕过升级约束。还原原生效记录除检查材料数据库状态外，还检查文件位于材料目录内、为可读取的非空实体文件；文件缺失、空文件、目录或越界路径均拒绝恢复计分。原材料齐全的正常还原流程、待补材料及失败记录的原状态保留不变。
