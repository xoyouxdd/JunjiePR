## 提交中及旧等级表单复查

进一步复现两处边界问题并修复：
- 提交尚未完成时Esc可关闭弹窗，可能造成已保存但界面未刷新。formModal新增默认关闭的lockWhileSubmitting选项，仅声明统计的类型、等级和作废/还原弹窗启用。启用后阻止提交中关闭及重复submit事件；成功后正常关闭并刷新，失败后恢复取消/提交按钮。其他页面继续使用原默认行为。
- 等级修改原先只核对原等级，没有核对其他操作已变更的类型和状态。该页面补传expected_type_id、expected_status，后台收到这些字段时校验并返回409冲突；原有仅携带等级的其他调用保持兼容，计分规则与权限不变。

本轮验证：新增2项旧等级表单冲突测试、原声明统计6项、原等级快照/历史分值2项，共10项后端测试通过。新增declaration_pending_ui.cjs在Edge/WebKit验证真实延迟提交、Esc拦截、取消禁用、重复submit只发送一次、成功刷新，以及其他默认弹窗仍可按原方式取消。declaration_admin_ui.cjs严格CSP完整操作回归和declaration_review_ui.cjs页面生命周期/失败/长文本/筛选导出回归，两种浏览器均通过。语法与diff检查通过。
