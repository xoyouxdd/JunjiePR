# 工作台紧凑展示与按需组件

版本：2026.10.27.1。本轮为本地接入，不代表已推送或上线。

## 保留的使用流程

- 菜单、默认页面、日期及状态筛选、查询按钮、服务端分页不变。混合类型登记记录继续使用原表格；纯认可结果可使用增强表格。
- 增强表格只接收当前接口返回的一页数据，默认保持原顺序。新增查找、待复核筛选和排序均明确标注为本页操作；跨页仍用上方筛选。没有根据前端隐藏字段扩展数据权限。
- 认可内容、提交时间、材料、月度上限和复核说明保留；桌面在对应行展开，手机在卡片内展开。撤回沿用原按钮、确认弹窗及接口，不增加自动重试。
- 待办原本已经按类别聚合，本轮只收紧展示。全部类别、服务端数量、严重程度排序、开始复核和查看明细等入口保留，不提前获取全部待办明细。直属复核仍取最早一条，原因必填、处理锁及切页保护保留。
- 当月统计默认入口、组织树、得分明细及导出不变。月度趋势默认显示整体与各景点圈分数合计，可切换人均；四项分数、曲线、数值表及较上月统一切换。每项人均为合计除以对应月份、对应范围的计分人数，整体按总分除以总人数，不平均各圈的人均；无人计分时显示横线并在图中留空。切换只使用当前数据，不新增请求、不修改计分规则。查看当月沿用当前筛选进入原当月统计；原趋势接口不使用员工关键词，而当月统计继续使用当前员工关键词。

## 资源与开销边界

- Tabulator 6.3.1：本地脚本 442,820 字节、CSS 28,359 字节；仅桌面纯认可结果按需加载。
- Apache ECharts 6.0.0 定向构建：本地脚本 513,463 字节，包含折线、坐标轴、普通/滚动图例、提示与 Canvas 渲染；仅打开月度趋势时加载。simple 原版不含所需提示组件，未用于交付。
- 两项 JS/CSS 共 984,642 字节（约 962 KiB，未压缩传输），不是每次进入首页都会下载。实际网络传输和缓存取决于部署配置，本轮不承诺压缩率或服务器性能提升。
- URL 保留门户前缀并携带当前静态版本；不依赖外部 CDN，不放宽现有 CSP。无新增数据库表、任务服务、轮询或统计接口。
- Tabler 仅作为布局设计参考，未引入其 Bootstrap/CSS/JS 依赖。
- 图表销毁、尺寸观察器和表格布局监听随页面清理；表格切换手机布局不重新查询接口。组件不可用时保留原表格或原 SVG 与准确数值表。
