# 头像及页眉插画串图裁剪修复（仅本地）

完整目录有71个头像。问题来自原始缩略图：部分底部已包含拼图下一行的内容，手机大尺寸选择器会放大这条边缘。首次只修正base-01前16个，复查其余55个后发现base-03-02（莓帽绒鼠）、base-03-03（玫羽小飞蛾）也有同类问题，现已补齐。

- 对18个头像建立64/160两种尺寸的自包含SVG裁剪视图，只保留当前头像的安全正方形区域；原WebP字节不修改，不重绘角色。其余53个经目视检查未发现相同串图。
- 头像列表、目录头像、个人预览、插画选择器以及首次加载/重载后的页眉插画均使用同一套修正路径。其他批次继续使用原资源。
- 保留头像key、收藏、最近使用、三套搭配、账号配置和原有框；无数据库或权限修改。
- 更新目录中的display_images尺寸、大小和SHA256；原images仍保留原始WebP合同。生成入口为scripts/build_avatar_crops.py，可重复生成，无外部图片请求。
