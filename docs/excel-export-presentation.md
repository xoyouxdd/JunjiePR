# Excel导出阅读优化（本地候选）

沿用既有查询、权限、统计及月结数据来源。保留原工作表名称、原字段顺序与全部记录，原分值与公式不改写；组织视图修正员工行姓名与工号错位。

- 月度文件默认打开“导出说明”；同页给出原有汇总、现有归属依据、数据更新时间与可点击目录。人员完整表与主管完整表前置，组织及层级视图继续保留。
- 人员完整表末尾追加来自原组织层级的小组名称；找不到历史小组时留空，不按当前组织推断。
- 历史工号、撤回、作废和部分操作字段在原位置按列分组折叠，可用Excel列标题上方的＋展开。姓名、工号、分值、状态、长内容仍可直接查阅。隐藏不等于删除；完整文件仍仅按原权限导出。
- 中文字体、列宽、换行行高、冻结识别列、打印重复表头统一处理。Excel行高有409pt上限；极长原文不截断，可在编辑栏查看完整值。
- PR表保持原数据表与条件字段，附加导出说明；超过5000人的导出按实际总数补取，数量不一致时提示重新导出，不静默交付截断结果。
- 声明汇总与明细保持原结构；缺勤未覆盖说明前置，源表行列不改写。
- 序列化后仅复用字节完全一致的图片。保留所有水印锚点、页眉页脚和归属信息，单元格XML及计算公式不因压缩而改写。

同批次虚构样本与核对记录见 `output/export-refresh-20261019/`。使用实际旧/新导出构建器生成文件，并以本机Excel打开、重算、打印核对。文件体积与构建耗时应以其中 `verification.json` 为准；压缩收益不代表服务端查询或网络下载耗时已经实测改善。未覆盖WPS、Mac及手机Excel兼容性。
