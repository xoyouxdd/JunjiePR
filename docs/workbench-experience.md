# 今日工作、连续登记与后台导出

本轮仅为本地实现。沿用所有原有权限、统计、月结快照、复核顺序和原始导出接口；不增加评价口径。轮岗专用临时账号仍只进入本人轮岗任务，不初始化通用工作台及导出任务。

## 操作方式

- 待办入口为“今日工作”。真实待办与原有数量来自 `/api/action-center`；声明升级仍只显示分配给当前账号的工单，并保留处理说明、真实开具确认和转交。原有明细入口保留。
- “常用工作”直接复用现有菜单计算，最多显示六项；更多功能仍在原导航中。不会因为快捷入口获得新权限。
- 直属组员的待复核签卡可直接进入逐条处理。仍按服务端原顺序，每次只读取一条，处理成功后重新读取最早待处理项；支持返回完整列表、历史和还原；不通过原因仍必填。相同记录的按钮共享写入锁。
- CM/TR本人认可登记增加“沿用上一条选择”，主动复制日期、类型、发生景点、签卡人。认可内容不复制，仍独立填写；签卡人重新加载并在当日候选中核对。照片只在本批1～5条中共用；成功提交后清除，不沿用至下一次提交。失败和结果不确定时沿用原有幂等键及表单保留规则。
- 景点数据、PR排名、声明统计、公告签收及跟进报告、三套月报PPT均可加入后台导出任务。提交素材期间仍有按钮锁；后台收到任务后允许切页。右下角任务面板显示排队、制作、完成、失败；完成后主动点击下载，兼容需要用户手势的移动浏览器。

## 导出运行约束

2026.10.24.4补强：复核操作在发起时固定直属/主管队列；已接受的原因确认即使恰好切页仍提交原队列，完成后不能重绘新页面。取消或未填不通过原因不提交，同条操作继续共用写入锁。导出任务创建与下载均保留门户部署前缀，不把前缀拼入服务端内部导出目标。

后台只允许上述固定入口，不是通用HTTP代理。单个执行器串行生成文件，最多四项接收/排队/执行中的任务、每账号最多两项。所有生成仍经过原HTTP接口，包括当前登录验证、权限、参数、照片上限、月报预览摘要、草稿、水印和原审计。

创建、开始执行和下载均核对当前权限及范围。任务仅本人可见、可下载；公告在下载时重新检查可见签收人员及跟进权限。会话凭据只在执行所需内存中短暂持有，不写入任务文件；输入素材在成功或失败后均清理。

普通GET导出不接收素材；PPT原始请求最多32MiB（照片原规则仍为最多12张、每张5MB、总30MB）。单份生成结果上限80MiB，完成文件缓存总上限256MiB。超过缓存总量时优先清理旧文件。文件最多保留30分钟；后续任务请求会清理过期文件及专用目录的旧孤立文件。账号停用、权限变化、服务重启或文件过期后需重新导出。

当前任务注册表为**单个后端进程内存**；刷新页面及同账号重新登录可查询，但不跨服务重启恢复，也不支持多worker或多实例共享任务。本轮不引入新的数据库任务表，不在重启时自动重放旧任务。横向扩容前应改为共享队列和持久任务状态。

仅对白名单导出中已回滚的SQLite BUSY/LOCKED事务最多重试三次，等待0.15、0.30、0.60秒；每次仍重新验证权限。不会自动重试认可提交、复核或轮岗确认。原同步导出接口保留兼容，因此旧客户端仍会使用原方式，不属于新队列的并发配额。

混合检查暴露并修复了轮岗连接池耗尽：鉴权和轮岗业务复用同一请求会话，独立时钟推进前释放只读事务；正式轮岗HTTP请求在进入鉴权和数据库依赖之前最多同时处理四个，其余异步等待，释放槽位前完成依赖清理。SSE沿用每次短连接鉴权，不占用长请求槽位。此限制不改变轮岗权限、时间推进或确认规则，也不扩大全局数据库连接池。

## 验收与边界

代表性五条认可在日期、类型、景点、签卡人相同时：手动字段填写/选择从25次降至9次，减少16次（64%）。这是字段操作数，不是人工总耗时或总体五倍提升；照片、加条、提交和阅读校验不在该指标内。

验证使用隔离数据库和合成数据；实际生成并读取XLSX/PPTX，实际浏览器加载生产模块，不把设计稿当成功能测试。截图、字段比较及15个并发HTTP读取的本地数据保存在 `.handover_review/task-workbench-20261024/`。第一次检查覆盖健康、待办和本人轮岗查询，同时运行真实Excel导出。

另有手动混合检查 `backend/.venv/Scripts/python.exe backend/tests/workbench_shared_load.py`：自动启动独立测试服务，15个不同的虚构TR账号通过真实视频播放鉴权读取4秒合成视频的64KiB Range片段，同时后台生成真实月报PPTX、读取待办和本人轮岗，结束后只停止自己创建的测试进程树。它不代表持续播放、手机实际帧率、大视频转码、运行中看板写入或生产硬件容量。正式轮岗的确认、权限与事务另有原有回归验证。

物理iPhone上的UC、百度浏览器及真实大视频混合负载仍需在明确的测试环境补验；本轮不连接或变更生产服务。
