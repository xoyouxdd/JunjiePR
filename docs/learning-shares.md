# 学习分享

学习列表支持分类和关键字搜索，输入中的通配符按普通文字查找。分享和修改稿增加分类字段，已有材料自动归入“未分类”。编辑可显式保存私人草稿，草稿只对本人开放；保存与发布核验版本，过期写入不能覆盖更新，发布失败保留草稿。修改他人材料由当前负责人确认。

阅读者可针对具体公开版本提交问题反馈，按权限查看反馈及回复；负责人处理反馈时校验版本并记录处理人和时间。反馈、草稿和普通阅读不产生新的周期轮询。正式主管、GSM、AM、OM及最高管理员可直接查看三个有效景点圈的已发布资料和附件；本职为正式主管、正在代理TA GSM的人员同样具备此阅读范围。旧申请的状态或到期时间不限制该阅读权限，也不触发到期清屏。编辑、发布、下架和交接仍遵守原有范围。CM/TR及仅有TA主管身份的人员跨圈阅读继续使用原有7天授权；临时主管认可资格不增加知识库权限。

学习分享是独立入口，三个有效景点圈并列显示。锁定资料只返回标题、负责人和更新时间等列表信息，正文、附件和修改稿由服务端单独鉴权。普通分享、星标及修改稿不产生公告签收或系统待办。

正文和已发布附件共用阅读鉴权，首先核验资料所属景点圈仍启用且属于员工景点圈。景点圈停用或不再属于员工景点圈后，旧资料链接与附件链接均拒绝读取；管理角色免申请阅读、所属景点圈身份及已有7天授权均不能绕过此检查。有效景点圈中的原阅读、编辑和审批规则保持。

私有附件和本人草稿详情复用同一有效景点圈检查；原有作者归属、编辑资格及未发布草稿仅本人可见的限制保留。草稿共用鉴权同时保护详情、修改、发布和删除入口。景点圈停用或新攻略草稿作者失去本圈发布资格时，相关草稿保留，资格恢复后可以继续编辑和发布。

本职为 TR、主管、GSM，或处于有效任期内的 TA 主管、TA GSM，可以向本人所属的有效景点圈直接发布。新攻略的发布人同时是首任负责人。该圈的 TR、主管、TA 主管、GSM、TA GSM 可参与修改，AM、OM、最高管理员按现有管理范围处理。具备本圈发布资格的当前负责人可直接更新，也可确认或退回其他人提交的修改稿。待确认期间保留公开版本，基于旧版本的修改稿须核对后重新提交。

代理到期后按本职和其他有效代理职务重新判断发布资格。负责人失去资格后，已有攻略继续按原阅读规则开放。主管以上可按现有管理范围交接给同圈在职、账号启用且具备发布资格的人员。交接保留原发布人、公开版本和未处理修改稿，操作进入审计日志。

每人每篇攻略可点赞和星标，重复设置不增加次数。星标列表按当前景点圈显示；跨圈授权到期后保留星标但恢复锁定。

跨圈申请由当前本组组长人工确认多资质。批准时间起算7×24小时，审批请求和代次号防止重复批准或旧请求续期。到期无需后台定时任务，所有正文与附件请求实时拒绝。申请人调圈后原授权不再生效；换组后由当前组长处理。只有待审批的跨圈申请进入组长待办。组长可以退回和提前撤销。没有当前组长时提示先核对分组，禁止自行批准。

材料支持正文、PDF、JPG、PNG、WebP；单份10MB，最多8份。上传校验真实格式，保存在独立的私有学习材料目录；不走会生成个性化水印文件的通用文件接口。读取使用共享原文件，身份水印在浏览器阅读框内叠加并随框高度重复排列，不在服务端渲染或为查阅者生成新副本。PDF 使用按需加载的本地 PDF.js 5.6.205，在浏览器逐页绘制；共享静态运行文件可缓存，不使用外部CDN，不在服务器转换，不生成个人材料副本。

前端水印用于阅读提醒与截图标识，不能阻止有权限者提取原文件、移除页面覆盖层或拍照；不应宣称等同数字版权保护。权限过期会清除当前页面的阅读框和临时浏览器对象URL；已经下载或取得的字节不能远程收回。页面切换会释放附件对象URL、中止读取及清理到期计时。普通浏览不做周期性后台轮询，点赞数量按当前分页批量聚合。新增数据表由幂等建表流程创建，不改旧业务表。

定向验证：`tests/test_learning_shares.py` 和 `tests/learning_shares_ui.cjs` 使用隔离数据与模拟员工；浏览器测试启动独立本地API，不连接正式系统。
