# 学习分享

学习分享是独立入口，三个有效景点圈并列显示。锁定资料只返回标题、负责人和更新时间等列表信息，正文、附件和修改稿由服务端单独鉴权。普通分享、星标及修改稿不产生公告签收或系统待办。

TR 可向所属景点圈直接发布。该圈的 TR、主管及代理主管、GSM及代理GSM可参与修改；AM、OM、最高管理员按管理身份处理。其他作者的修改先保存待确认稿，原发布TR（交接后为当前负责TR）核对正文及附件后发布或退回。发布前保留公开版本；旧版本修改稿必须核对最新公开内容重新提交。主管以上可下架或交接给同圈有效TR；交接保留原发布人和未处理修改稿，操作进入审计日志。

每人每篇攻略可点赞和星标，重复设置不增加次数。星标列表按当前景点圈显示；跨圈授权到期后保留星标但恢复锁定。

跨圈申请由当前本组组长人工确认多资质。批准时间起算7×24小时，审批请求和代次号防止重复批准或旧请求续期。到期无需后台定时任务，所有正文与附件请求实时拒绝。申请人调圈后原授权不再生效；换组后由当前组长处理。只有待审批的跨圈申请进入组长待办。组长可以退回和提前撤销。没有当前组长时提示先核对分组，禁止自行批准。

材料支持正文、PDF、JPG、PNG、WebP；单份10MB，最多8份。上传校验真实格式，保存在独立的私有学习材料目录；不走会生成个性化水印文件的通用文件接口。读取使用共享原文件，身份水印在浏览器阅读框内叠加并随框高度重复排列，不在服务端渲染或为查阅者生成新副本。PDF 使用按需加载的本地 PDF.js 5.6.205，在浏览器逐页绘制；共享静态运行文件可缓存，不使用外部CDN，不在服务器转换，不生成个人材料副本。

前端水印用于阅读提醒与截图标识，不能阻止有权限者提取原文件、移除页面覆盖层或拍照；不应宣称等同数字版权保护。权限过期会清除当前页面的阅读框和临时浏览器对象URL；已经下载或取得的字节不能远程收回。页面切换会释放附件对象URL、中止读取及清理到期计时。普通浏览不做周期性后台轮询，点赞数量按当前分页批量聚合。新增数据表由幂等建表流程创建，不改旧业务表。

定向验证：`tests/test_learning_shares.py` 和 `tests/learning_shares_ui.cjs` 使用隔离数据与模拟员工；浏览器测试启动独立本地API，不连接正式系统。
