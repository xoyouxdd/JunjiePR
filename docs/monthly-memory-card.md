# 本地月度回忆卡

本次为本地源码候选，未自动推送、打包或上线。回忆卡位于「我的成绩」月份选择下方，与原版月度勋章并列；勋章原有素材、动画、月结条件和荣誉收藏功能不变。

CM、TR、代理TA主管（TALEAD，对应 TA_SUPERVISOR）和主管（LEAD，对应 SUPERVISOR）沿用本人计分首页。回忆卡复用 `/api/dashboard?month=...` 的本人记录，不新增业务接口、数据表、权限或计分规则。临时轮岗身份不能使用。只纳入所选月份、本人、已确认且存在文字的认可，封顶后零计分记录仍保留；POC理由与内容不同时同时保留。没有已确认认可时显示空状态，不产生寄语或图片，不依赖勋章及月结是否生成。

## 文案

`monthly-memory-copy.js` 包含8类原创主题、40个标题、40句开头、40句结尾和54个主题词。表达参考正式报道的朴实、庄重与具体叙事，不复制媒体原文，不接AI或外部服务。事迹段保留原话，装饰性文字不推断游客满意度、团队效率等未经记录的结果。

当前自动生成仅从综合、通用和朴实叙事模板中选择，主题词库保留为储备，避免用简单关键词误判事迹。以本人ID、月份和文案版本作为稳定种子，浏览器按最近访问顺序保存18个月份的选择，重新查看旧月份也会保留该次选择；生成尚未保存的月份时，优先避开与所选月最接近的6个已保存月份用过的同类句式，正序和倒序查看均适用。已生成月份的句式保持稳定，换插画、重开卡片和导出不重新随机。浏览器清理存储、其他设备或首次按不同月份顺序查看时，选择可能不同；不承诺跨设备去重。存储受限时使用稳定种子回退，仍可查看和导出。

## 插画与导出

完整71张插画来自既有头像目录，第一次展开选择器才读取静态目录，分页8张，图片懒加载。回忆卡插画与个人头像、首页插画相互独立；选择仅按本人ID保存在当前浏览器，不写服务器。

PNG在浏览器Canvas生成，带本人姓名和所选月份，不包含勋章、分数、员工号或他人隐私。使用文字测量分页，长内容全部续页，不截断原话，也不创建超高单张Canvas。单页尝试直接下载；多页提供每张图片的下载入口，避免浏览器连续下载限制。图片生成后支持长按保存；浏览器支持文件分享时显示系统分享按钮。手机系统能否直接存入相册，须以真机浏览器行为为准。

换月、切页或收起时清理事件和Blob URL；旧的异步插画请求或图片生成不能写回新页面。生成失败可重试，原始记录不受影响。

## 本地验证

`monthly_memory_ui.cjs` 使用真实前端模块、严格CSP及隔离示例数据，覆盖三浏览器、四身份、320/390/768/1440宽度、零计分认可、其他员工/月份/状态过滤、原版勋章、PNG下载、长文本分页、部署前缀和存储受限回退。`test_monthly_memory_source.py` 在临时内存数据库验证四身份的真实dashboard数据边界。正式权限与业务仍由既有服务端接口决定。

只读验收页生成在 `output/appearance-preview/monthly-memory.html`，展示真实模块与示例数据，不连接真实员工账号；截图及结果同目录保存。本地8000端口的实际应用由原有本地服务提供。

复查补充：分页同时保存原始换行和自动折行数据，原话中的换行及空行在预览和导出中保留。字体就绪后导出会重新测量，并同步刷新当前预览和张数。每次展开绑定姓名快照；较长姓名在PNG封面中完整换行，并相应增加封面高度。

二次复查补充：文案缓存按访问顺序淘汰，不按月份新旧淘汰；同一月份只要仍在最近访问的18个月份中，标题、开头、结尾保持稳定。超过18个其他月份未再访问的条目可能被淘汰，再次查看时可能重新选择；浏览器清理存储和跨设备同样不保证历史选择一致。

插画失效回退：只处理当前仍显示的图片错误；旧图片迟到的错误不重置新选择。回退默认插画时取消旧导出、撤销旧图片URL并同步素材选中状态，旧异步错误不能覆盖新的回退提示；可重新生成默认插画回忆卡。
