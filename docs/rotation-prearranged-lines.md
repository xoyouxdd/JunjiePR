# 预排线路启停（仅本地）

预排线路标题原先没有交互属性及事件绑定，所以右键D2/E标题不会打开开线设置。本次在原预排界面补齐线路操作，不增加入口。

- 可编辑预排中，点击或右键线路标题打开启用/停用确认框；键盘Enter/空格也可操作。
- 启用只保存所选日期的线路预排，按岗位配置开放对应岗位，之后可以拖拽安排人员；未来日期不提前开始轮岗计时。
- 所选日期发布后保留该线启用状态，不修改默认模板及其他日期。
- 停用只释放本线预排人员，其他线路安排和仍有效的推7点接替关系保持。岗位名称、岗位标识和定时开岗配置保留。
- 今日首班前的已启用预排可同步到看板；首班后、历史日期及开班安排回顾不开放操作。版本冲突仍拒绝旧修改。
- 正式接口仍要求原有主管/经理管理权限，CM/TR不能直接调用预排线路修改。大屏和普通只读看板不增加管理入口。
- 使用原每日班表保存流程，保留已有滚动位置与刷新处理；操作写入预排线路启停日志。

验证：每日班表51项通过，覆盖D2/E启用、安排、停用、只改当天、发布后保留、不提前计时、其他推7点关系保留、非法参数及陈旧版本。正式轮岗原39项通过，并扩展首班前同步/首班后只读/CM与TR接口拒绝用例。浏览器在Edge/WebKit使用真实隔离API验证右键、点击、键盘、启用后拖拽、停用释放和窄屏布局；7点岗位原验证也保留。JS语法及diff检查通过。
