# 个人月结游戏段位（未发布）

段位展示个人月度PR积分的相对位置，仅供本人参考，不代表综合工作表现，不构成独立绩效评价结果，不增加奖惩或改变正式绩效流程。

## 保留的业务规则

- 不改PR加分、类别封顶、POC、全勤、扣分、签卡或LOA规则；复用`employee_month_scores`两位小数有效积分。
- CM/TR及代理TA主管（TALEAD）使用月结景点圈内的一线计分人群。
- 正式主管及代理TA GSM从2026年10月起合并全部参与圈，所有参与主管计分的圈月结后才生成。
- 保留月结事务、组织快照、历史封存、全局关闭优先和重开失效。LOA排除，不凭当前身份重新构造历史人群。
- 月份沿用现有下拉框，历史组织信息和签卡汇总对应所选月份。一线PR计分说明继续隐藏。

## 算法和十档名称

经确认使用同分中位百分位：`(严格低分人数 + 同分人数 / 2) / 比较人数`，同分人数包含本人。比较人数至少10人；所有人同分时不生成段位，不强制各档人数，不拆分同分人员。

内部沿用原有严格分档边界，以整数交叉相乘判断：`50 × (2 × 低分人数 + 同分人数) > 档值 × 总人数`，不先四舍五入百分位。精确位置只用于计算，员工界面不显示百分位、超过多少同事或名次。

| 内部档值 | 游戏段位 |
|---|---|
| 90 | 无双王者 |
| 80 | 傲世宗师 |
| 70 | 超凡大师 |
| 60 | 璀璨星耀 |
| 50 | 永恒钻石 |
| 40 | 流光铂金 |
| 30 | 荣耀黄金 |
| 20 | 探索白银 |
| 10 | 成长青铜 |
| 0 | 启航新星 |

例：8人12分、1人13分、1人14分。原算法将12分组放在最低档，新算法取同分组整体分布的中位位置，对应荣耀黄金。本地库无有效计分或月结样本，未读取线上真实分布；此例仅用于算法说明。

## 主动查看和隐私

按最新确认，符合计分身份的员工默认可以看到「查看我的月度勋章」入口，是否点击由本人决定。`RECOGNITION_ENABLE_MONTHLY_RANKS`未设置时默认启用，明确设为`0`仅用于维护或回退停用；普通月份未月结、人数不足或全员同分不会隐藏入口，点击后显示相应提示。当前只修改本地代码，不自动部署或新增员工通知。

首页查询不加载段位。本人点击「查看我的月度勋章」才请求`GET /api/self-month-rank?month=YYYY-MM`，展开后按钮为「收起我的月度勋章」；换月重新保持未展开，旧请求不能覆盖新月份。勋章对应当前选中的计分月份，沿用原游戏段位算法。接口只使用当前登录员工，不接受指定他人身份；非计分身份不能访问。

展开后保留徽章、四季背景、个人月度PR积分和季节寄语。通过「了解月度勋章」折叠说明计算原则及用途，不恢复一线总分公式入口。图片复用`static/images/ranks/rank-emblems-v2.png`与`rank-seasons-v2.png`。

有效勋章由本人主动查看后展示。新星与青铜保留简洁的逐层显现；从白银开始使用八套独立动作，而非同一条飞入/展翼时间线只放大强度。动画由可独立控制的盾身、左右翼、冠饰和原勋章纹理，以及代码绘制的银环、金纹、星核、秘印、蓄势光环、王座构成，完成后还原原勋章。各档约3至5.4秒，只改呈现，不新增业务段位。

| 段位 | 专属动作 |
| --- | --- |
| 白银 | 左右银环先扣合，中央勋章显形 |
| 黄金 | 盾身从底部铸成，金色轮廓和纹路依次点亮 |
| 铂金 | 底座浮现，主体轻落，双翼平顺展开 |
| 钻石 | 晶徽从侧面翻转到正面，晶面扫光后定格 |
| 星耀 | 中央星核先亮，盾身升起，双翼张开，星芒划过 |
| 大师 | 背后秘印先开启，主体从印中推出，双翼分两次伸展 |
| 宗师 | 双翼合拢包住主体，停顿蓄势后再展开，名字压印出现 |
| 王者 | 背景压暗，王座升起，主体落座、金翼展开，最后王冠落下、名字亮起 |

待月结、重开、人数不足等状态不播放。等待图片解码成功再开始，失败直接显示静态结果。可随时跳过、完成后重播，重播不请求接口；收起和换月终止展示与声音。系统开启减少动态效果时直接展示静态内容。只改前端呈现，不改变段位计算、权限或月结逻辑。

音效默认关闭，每次重新查看恢复关闭。新增独立「试听音效」，点击立即播放实际WAV文件；「音效：开」同时播放一次确认音，之后重播随各档专属动作的关键时刻同步播放。音频位于`static/audio/medal-soft-seal.wav`，约0.72秒，柔和泛音与45毫秒渐入、快速衰减，无突然重低音；文件峰值0.20，播放器音量0.45，不随档位加大音量。使用原生audio播放，显示播放/失败提示；减少动态效果时仍可主动试听。关闭、跳过、收起、换月或离开页面暂停并复位。离线预览另提供原生音频播放器，便于排查本机是否有声。

按本轮仅本人可见要求，撤回未发布的组长段位访问扩展。`/api/member-score-summary`恢复原`MEMBER_RECORDS`权限，不返回任何组员段位；无原权限的负责人不能访问。原授权PR记录、统计和导出不改，不把游戏段位附加到这些结果。

## 追溯、异常和回退

快照保留分数组成、比较人数、严格低分人数、同分人数、计算版本及跨圈关闭联合签名。当前版本`midrank-v2-min10`；幂等新增`equal_count`与`rule_version`两列，旧行标记`strict-lower-v1`，不删除或覆盖旧结果。

旧规则结果暂不展示，不在启动或读取时静默转换。不足10人、全员同分、LOA、未月结、重开、缺少历史依据和规则不匹配分别处理。再次月结沿用原代次封存流程生成当前规则结果。历史首次补建按月份顺序生成，寄语只比较连续、有效且可比的本人积分；封存后保持稳定。

明确关闭功能开关并重启应用可停止员工访问，仅用于维护或回退。新增列与旧代码兼容，优化前源文件副本位于`.handover_review/rank-incremental-20261014/before/`。回退界面或算法时保留维护开关及仅本人访问限制，不部署旧版组员段位权限；保留PR数据及新增列，不删表、不做降级迁移。存在后续修改时应先比对，避免覆盖。

## 验证

### 2026-10-19 我的荣誉

首页原「查看我的月度勋章」入口内增加「我的荣誉」：荣誉典藏、高光回顾、自由装扮三个页签。保留首页月份选择和仅本人主动打开的方式，典藏显示最近12个月；完整历史仍可通过月份选择查看。管理身份不因此取得他人的勋章或认可寄语。个人界面不展示十档阶梯、档位序号、超过多少人或最高级说明。

装扮为星海、鎏金、月白、冰晶、墨玉、赤铜、林光、简洁。八款均直接可用，未生成勋章时也可预选，不与积分或档位绑定；底座、边框、形状与材质分别处理。风格切换不自动重播，页签切换、收起、换月或离页会终止旧动画与音频。裁切改为相接并略有重叠的连续区域，完整图在原场景内渐入、组成层渐隐，避免收尾替换DOM。

`GET /api/self-honors?month=YYYY-MM`只读取登录本人：已确认的有效认可（包括类别封顶后未计分的认可）、本月寄语来源、选择与收藏、装扮及最近历史。待复核、不通过、作废和撤回不进入回顾。排序仅按原文是否包含具体行动、场景与结果线索，再按日期和记录ID稳定排列；不用字数、签卡人身份或分值排名，不修改原认可或绩效顺序。算法是有限关键词辅助整理，不能保证理解每一条文字，允许本人选择全部有效原文。

月度寄语采用本地确定性文案整理，引用最多3条实际原文及日期、类别，使用克制的感谢文字。不调用外部模型，不上传员工资料，不补写影响、事迹或他人评价。每条来源可以展开核对。有效月结后生成；未月结、重开、主管尚未满足全圈封存或历史依据不完整时不生成。没有有效认可时展示空状态，不凑写寄语。来源被作废后即时移出回顾，已选记录失效时回落到当前有效原文。

`PUT /api/self-honors?month=YYYY-MM`仅接受`skin`、`selected_record_id`、`favorite`，额外身份字段拒绝；精选记录必须属于本人及所选月且有效。装扮保存至`employee_honor_styles`，月度选择和收藏保存至`employee_honor_memories`，均以员工主键归属。偏好不进入计分或月结快照，写入审计。两张新增表沿用启动时`Base.metadata.create_all`幂等创建；不更改旧表、不回写或重算封存分数与历史评语。接口响应使用`private, no-store`。
