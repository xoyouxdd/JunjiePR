# HR 月报模板字段与系统映射

本目录是原始模板评审版，全部模板数据为示例，不代表正式统计。系统一键导出已在本地接入，运行时替换示例内容；接口、权限和操作说明见[接入说明](../../../hr-monthly-report-plan.md)。尚未部署生产。

| 章节 | 模板字段 | 现有来源与接入约束 |
| --- | --- | --- |
| 封面 | 月份、报告范围、草稿状态 | 用户月份与显式授权范围，MonthClosure 判断范围月结状态 |
| 概览 | 统计人数、认可数量、处分数量 | statistics_payload 基础数据，记录数和涉及人数分别统计 |
| 减分分类 | 景点圈、人员类别、类型、次数 | DeductionRecord，事件所属月，景点快照，升级关联去重；次数不可称实际扣分 |
| 加分分类 | 景点圈、人员类别、类型、次数 | RecognitionRecord 已通过记录，事件归属与角色快照 |
| 认可发放 | 发放人、发放数量 | recognizer 与 operator 必须区分，不重复累计 |
| 认可统计 | 认可数量、统计人数、认可率、历史月份 | 认可率为认可数量除以统计人数乘以 100%，可以超过 100%，并非覆盖率 |
| 小组分排名 | 小组、计分人数、平均分 | 复用现有计分，历史分组使用 EmployeeMonthOrganizationSnapshot |
| 优秀员工 | 候选、确认名单、说明 | 系统候选经用户确认，未确认跳过，不编造事迹 |
| PR 排名 | 加分、实际扣分、全勤分、综合分 | 复用现有底层计分，LOA、月结、上限和排名规则保持一致 |
| 工作说明 | 标题、内容、生效日 | 人工补充 |
| 活动 | 照片、说明、日期 | 用户上传授权素材，保持比例，无上传跳过，可分页 |
| 生日 | 名单、祝福、素材 | 人工提供，员工模型无生日字段 |

## 接入约束

仅 GSM、AM、OM、SYSTEM_ADMIN 允许制作和导出。用户已确认 GSM 可选择任意月份、任意单圈或全部景点圈；这不扩大登记、审核、作废或附件访问权限。

LOA 涉及月份保留记录，但不进入实际计分及对应排名。历史归属使用当月组织快照或事件快照，未月结标草稿，缺失数据明确提示。分类图示例使用记录次数，不能与原始分值和实际计分混用。

模板排名每页最多 8 人，日期、工号为文本；各章节可隐藏。系统接口已实施前后端权限校验、水印和导出审计。认可发放数量按签卡人 recognizer 统计，不按代录人 operator 重复累计。
