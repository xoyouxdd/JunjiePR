# 轮岗显示逻辑统一（仅本地）

本次修复覆盖大屏、正式看板、手机待办、旧个人直达页及记录时间显示。不改轮岗引擎、派发窗口、餐休长度、步骤凭证、角色权限、数据库结构或历史记录，不推送、不部署。

## 修复内容

1. 同线异常、前序等待及异常暂停任务优先展示暂停状态。手机和旧个人页不再显示旧路线、旧任务比较图或确认按钮；恢复后显示最新正式任务。
2. 当前任务模式下，仅已正式派发的任务可显示去向。未派发期间展示实际餐休结束时间及剩余时长，手机、旧个人页和待办文案均不提前显示预计算岗位；未来班表的预排编辑仍保留。旧的未完成待办在读取时投影为当前文案，不改写已完成记录或原始历史正文。
3. 旧个人页补齐超时知晓、重新领取入口；连续在岗使用continuousStart，餐休按实际readyAt显示，不再以预计出发时刻延长餐休。撤销和作废的旧回执不作为当前确认展示。
4. 后台已有timingUnverified标记在看板、大屏、手机及旧个人页明确显示“历史时间待核实”。个人页将当前分钟数标为“核实后已记录”，不改原计时数据。
5. 时刻显示统一保留实际分钟，不再四舍五入到下一分钟；允许出发、确认截止及后台记录时间含有效秒时显示秒。倒计时按剩余时长向上取整，实际可操作边界仍由原后端规则验证。

大屏确认、手机本人确认、授权主管确认继续共用后端完成状态。已完成的前序任务可正常顺接，无需本人再次用手机确认。CM只读、TR及主管原有能力、大屏仅确认权限均保留。
