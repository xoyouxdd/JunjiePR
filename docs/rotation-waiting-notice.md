# 轮岗看板等待匹配提示隐藏（仅本地）

共享轮岗看板的workflowTimeoutBanner原先逐条显示timeoutWaitingMatch，积累时将岗位及人员区挤到下方。现仅移除此组“顺接后的需求等待匹配”提示的可见渲染，适用于大屏及普通看板。

后台待匹配数据、任务顺接、自动匹配、轮岗规则及权限不变；真正的关联任务待核实异常、原有处理入口及强提醒保持原逻辑。

rotation_waiting_notice_ui.cjs在Edge/WebKit验证500条等待项不渲染、不改变看板起始位置、不修改传入数据，实际异常仍显示，操作按钮仍仅限操作人员。必要语法及diff检查通过。仅本地修改，未推送、未上线。
